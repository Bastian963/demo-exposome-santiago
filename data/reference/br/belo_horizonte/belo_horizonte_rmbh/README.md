# Belo Horizonte — RMBH municipal reference

`spatial_units.geojson` contains exactly the 34 municipalities in the legally IBGE Região Metropolitana de Belo Horizonte (RMBH), not the separate Colar Metropolitano. Membership comes from IBGE's Recortes Metropolitanos WFS snapshot and geometry from the IBGE Minas Gerais Malha Municipal Digital 2024. `unit_id` is IBGE `CD_MUN` (seven digits); `unit_name` retains the MMD spelling. The exact downloaded files, checksums and URLs are frozen in the matching `data/raw/br/belo_horizonte/ibge_rmbh/2021-2024/source_manifest.json`.

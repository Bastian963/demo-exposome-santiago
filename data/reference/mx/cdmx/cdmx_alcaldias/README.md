# CDMX alcaldias spatial reference

`spatial_units.geojson` holds the 16 alcaldias of Ciudad de Mexico (CVE_ENT 09), filtered from INEGI's Marco Geoestadistico municipal layer ("Division politica municipal, 1:250000. 2022", CONABIO mirror, CC-BY-NC 2.5 MX -- cite INEGI/CONABIO, non-commercial use). `unit_id` is `cdmx_<cve_mun>` (3-digit INEGI municipio code within the entity); `unit_name` is INEGI's own `nomgeo` spelling, source-faithful (not re-accented or stripped) -- same convention as data/reference/ar/buenos_aires_amba/buenos_aires_amba.

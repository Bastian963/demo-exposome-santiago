# Barcelonès — piloto MER 2022

Este límite contiene únicamente la comarca **Barcelonès** (`unit_id: cat_13`),
extraída mecánicamente del inventario ICGC versionado para
`cataluna_comarques`. Es el soporte administrativo publicado del piloto de
ruido SICA/MITECO; no es el municipio de Barcelona ni la huella de una
aglomeración SICA.

Fuente: ICGC, `comarques_5000`, CC BY 4.0. El producto de ruido puede cubrir
sólo una parte de esta comarca: las métricas nulas indican falta de contorno
modelado >=55 dB(A), no condiciones silenciosas.

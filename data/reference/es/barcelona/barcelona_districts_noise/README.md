# Barcelona — distritos municipales

`spatial_units.geojson` contiene los diez distritos municipales de Barcelona, derivados de una descarga local de la capa oficial de districtes del Ajuntament. `unit_id` y `unit_name` preservan las columnas de la fuente indicada en `metadata.json`; no se fabrican códigos ni nombres. La referencia sirve sólo para `barcelona_districts_noise`, no para barrios ni para la comarca Barcelonès.

Portal oficial: https://opendata-ajuntament.barcelona.cat/data/dataset/808daafa-d9ce-48c0-925a-fa5afdb1ed41/resource/5f8974a7-7937-4b50-acbc-89204d570df9/download

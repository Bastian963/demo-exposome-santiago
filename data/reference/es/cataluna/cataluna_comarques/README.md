# Catalunya (comarques) spatial reference

`spatial_units.geojson` covers the 43 comarques of Catalunya (ICGC `divisions_administratives_comarques_5000` layer -- 42 official comarques plus Val d'Aran, which this source treats as an ordinary comarca). `unit_id` is `cat_<CODICOMAR>`; `unit_name` is ICGC's own `NOMCOMAR` spelling verbatim (accented, source-faithful).

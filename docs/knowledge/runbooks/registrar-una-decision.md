# Registrar una decisión

Usa un ADR cuando la decisión afecte contratos, reproducibilidad, resolución
espacial, proveedores, propiedad de artefactos o compatibilidad entre estudios.

1. Obtén el siguiente número en `docs/adr/`.
2. Usa la [plantilla ADR](../templates/adr.md).
3. Describe contexto, decisión, alternativas y consecuencias.
4. Enlaza reuniones, capas y estudios relacionados.
5. Actualiza la metodología o el runbook afectado.

No crees ADR para tareas pequeñas o hallazgos todavía provisionales.

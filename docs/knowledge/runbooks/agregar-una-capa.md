# Agregar una capa

1. Implementa el módulo importable y declara dependencias en `pyproject.toml`.
2. Agrega configuración de capa, cobertura por país y estudios aplicables.
3. Define artefactos, columnas y contrato de integración.
4. Crea o asigna una metodología canónica con fuentes y limitaciones.
5. Incorpora la capa al inventario de auditoría y a sus pruebas.
6. Regenera el dashboard y el catálogo de Obsidian.
7. Ejecuta las pruebas completas y verifica la release cuando exista.

Si la capa tiene soporte espacial fino, sigue además
[Publicar y verificar resolución espacial](publicar-resolucion-espacial.md):
fuente, observación, análisis y mapa deben declararse por separado.

No reutilices datos de Santiago para países sin cobertura del proveedor.

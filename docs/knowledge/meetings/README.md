# Reuniones de grupo

Este directorio contiene minutas revisadas y aptas para compartir en Git. Usa un
archivo por reunión bajo `YYYY/YYYY-MM-DD-tema.md`.

La transcripción original se pega primero en
`local-notes/meetings-inbox/YYYY-MM-DD-tema-raw.md`. Antes de publicar una minuta:

- elimina credenciales, datos personales e información sensible;
- resume el contexto y las decisiones;
- asigna responsable y fecha a cada acción;
- enlaza capas, estudios, metodologías o ADR relacionados;
- conserva una transcripción revisada solo si aporta valor.

Consulta [Procesar una reunión](../runbooks/procesar-una-reunion.md) y la
[plantilla](../templates/reunion.md).
